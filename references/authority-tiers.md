# 来源性质、效力与时间适用核验

本文件提供跨法律领域的核验流程。具体法源地位和冲突规则随法域、规范种类及版本判断，不把固定的法条号或简单排序当成通用答案。

## 来源与权威性

开始外部法律检索前，先执行 [法律数据库 MCP 检查](legal-source-connectors.md)：检查威科先行、北大法宝等连接器，验证已有授权能力并记录实际检索路径。此步骤不能被普通网页搜索代替；专业库不可用时继续官方来源检索。

先记录法域、制定或发布机关、文件性质、文号/版本、权威文本入口。优先核对制定机关、法院、监管机关或官方数据库原文。二手文章可作线索，须标明观点出处和仍需回查的一手依据。

区分法律规范、司法解释、法院判决、行政决定、标准、官方指南、教材和评论。官方发布不意味着每份文件都具有同样法律效力。标准或指南是否具有约束力，应核验其性质、适用范围及相关规范如何引用，不凭文件名称判断。

案例注明材料类型、来源完整程度及程序状态。将某类案例用于类案论证时，核验当地关于参照与引用的规则，不把摘要等同完整裁判，不把实务启示冒充机关结论。

## 每份规范的核验记录

1. 名称、制定机关、法域与适用对象。
2. 具体文本版本；全文与条/款卡分别定位。
3. 公布日期、施行日期，以及相关修改、废止或过渡信息。
4. 当前有效性：区分整体状态与部分条款变化。
5. 资料性质与规范作用；不能确认时保留待核验并说明原因。
6. 实际核验的权威来源和日期。

发现新文本不自动代表旧文本在所有历史问题中都失去价值。保留旧版本及对应时间范围，更新当前入口。

## 处理冲突和时间问题

先确定事实发生时间、地点、主体和活动，再检索适用的冲突、授权、过渡及时间效力规则。不要将“新法优先”“特别规定优先”当成不附条件的机械判断，也不要仅靠发布日期决定具体事实适用哪个版本。解释或适用有争议时记录冲突双方、来源与未决问题。

当前源无法访问、文本版本不清或事实不足时，允许继续搭框架和整理来源，但不得把相关法律结论标为已核验。

## 来源变化后的维护

记录新旧差异、依据和影响范围；从规范卡出发检查引用它的概念、案例分析、专题与产出。对仍需复核的下游笔记设置 `核验状态: 待复核` 并说明原因。更新结论及索引后才恢复状态，保留历史解释所依据的版本。

以上核验在本次建库/更新任务中执行。定期监控须使用实际可用的调度机制，不能仅在笔记中写“每周更新”就声称已经安排。
